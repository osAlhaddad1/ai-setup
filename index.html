// Technical FAQ

Your IT Team Will Ask. We Answered.

How do we update models when new architectures are released?
We utilize standard containerized environments (Docker/Kubernetes). Updating a model requires pulling the new weights into the persistent storage volume and restarting the inference container. No hardware changes are required unless VRAM requirements exceed current capacity.
Can we integrate this with our existing internal databases for RAG?
Yes. The software stack includes vector database integration (e.g., Qdrant, Milvus, or pgvector running locally) and embedding models to execute Retrieval-Augmented Generation entirely within your local network.
What happens if a GPU fails?
Multi-GPU enterprise tiers utilize redundant configurations. If a single GPU fails, the inference engine dynamically reroutes processing to the remaining GPUs at a reduced throughput until hardware replacement occurs.
What are the cooling requirements?
Server rooms must support HVAC heat dissipation equal to the total power draw of the selected tier (e.g., Tier 2 requires dissipation of 2.8 kW of continuous heat output).
